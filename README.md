# Service-preserving generative MTD: data-only v2.2.0

This release contains 1,628 selected evidence files and no manuscript. It extends v2.1.0 with four accepted Juice Shop service-scope generations, four RealWorld API generations, and a bounded frontend/backend facade and deterministic adaptation comparison. S0/S1/S2 three-arm cohorts remain excluded.

Start with `V2_2_RESULTS.json`, `RESULTS_INDEX.md`, and `DATA_DICTIONARY.md`. Run `python scripts/verify_release.py` to validate the ZIP and all file hashes. The target applications, provider environment, and raw transcripts are not deposited.
